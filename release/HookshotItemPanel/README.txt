Hookshot Item Panel
===================

A small Windows window for single-player Zelda: Ocarina of Time running in Hookshot (v2.0.2).
It edits numbers in the running game's memory: rupees, bombs, bombchus, deku nuts/seeds/sticks,
business scrub seeds, magic beans, Gold Skulltula tokens, hearts, magic, carry limits, and Epona's
carrots. Tick Infinite on an item to hold it at the number you type, or use Set to write it once.
Nothing is injected and no game files or save files are changed.

HOW TO USE
1. Start Hookshot and load your save. Get into the world.
2. Run HookshotItemPanel.exe (no install, no .NET needed). Put it in your Hookshot folder, next to
   image.bin, or pick image.bin when it asks (it only reads the first 64 bytes of it, to find the game).
3. Wait for the green "Connected" line, tick Infinite on what you want, click Activate.
4. Epona carrots: ride Epona first. The panel finds her carrot counter by itself in a few seconds.
5. Close the panel with the X so it remembers your numbers.

GOOD TO KNOW
- Windows 10/11, 64-bit. Tested with Hookshot v2.0.2 only. A different build or version may put
  the numbers somewhere else; the panel refuses to write when what it finds does not look right.
- Back up your saves before trying anything. You use this at your own risk.
- Windows Defender or another antivirus may flag any program that edits another program's memory.
  If it blocks the file, that is why. Only allow it if you trust where you got it.
- Single-player only. Do not use it online.
- If a number will not go above a limit, raise that item's limit first (Limits section).
